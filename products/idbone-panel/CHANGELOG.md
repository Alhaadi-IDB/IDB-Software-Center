# IDBOne Panel: changelog

All notable user-facing changes to IDBOne Panel are documented here. Select a version or year to expand its notes.

**Latest version:** 1.2.3 · 28 October 2026  
[User guide](README.md) · [Earlier updates](#earlier-updates)

## Version history

<details open>
<summary><strong>Version 1.2.3</strong> · 28 October 2026</summary>

### Improved

- Updated application components to improve compatibility and reliability.
- Refreshed dropdowns, file selection, country flags, and notifications for the latest supported versions.

### Fixed

- Resolved a compatibility issue affecting image processing.

### Known limitation

- The latest image-processing security updates require a coordinated update of related components and are not yet included.

</details>

<details>
<summary><strong>Version 1.2.0</strong> · 5 October 2026</summary>

### Added

- The current application version now appears on the manual sign-in screen.

### Improved

- Sign-in checks for property and MSN details now appear only where required, with clearer messages for each field.

</details>

<details>
<summary><strong>Version 1.1.0</strong> · 1 October 2026</summary>

Changes delivered from 15 September through 1 October 2026.

### Added

- Added ONE Event certificates, including participant requests, approvals, and certificate management.
- Added individual and group certificate approvals, progress tracking, and retries when certificate preparation fails.
- Added certificate delivery by email, resend options, delivery history, and editable recipient addresses.
- Added email broadcasts with clearer validation, status, and results.
- Added the last printed date to ONE Event reports.

### Improved

- Improved certificate views, event grouping, approval and revocation details, and participant cards.
- Added an image preview for public certificates, with access to the full PDF.
- Improved public event check-in, certificate verification, and duplicate-action protection.
- Improved incident listings and forms, date selection, chat tiles, and termination filters.
- Improved layouts across screen sizes and made event report filenames more consistent.
- Updated organization branding and clarified a training evaluation question.

</details>
